Producer–Consumer Task Simulator suing C++

This project is a C++ implementation of the classic Producer–Consumer problem, a fundamental concept in Operating Systems and concurrent programming. It demonstrates how multiple threads coordinate while accessing a shared resource using synchronization mechanisms. The system models a producer thread that generates tasks, a consumer thread that processes those tasks, and a bounded buffer that enforces capacity constraints. Thread safety and correct coordination are achieved using mutex locks and condition variables.
In concurrent systems, multiple threads often need to access shared resources simultaneously. Without proper synchronization, this can lead to race conditions, data inconsistency, and buffer overflow or underflow scenarios. The Producer–Consumer problem captures this challenge by enforcing that producers must wait when the buffer is full, and consumers must wait when the buffer is empty, ensuring safe and correct execution.

This project demonstrates thread creation and management in C++, safe access to shared memory, and synchronization using mutex locks and condition variables. It highlights how buffer overflow and underflow are handled correctly and how coordination between concurrent threads is maintained through signaling mechanisms.
The implementation is structured around a shared bounded buffer, implemented as a fixed-size queue that stores tasks produced by the producer thread. The producer generates tasks and inserts them into the buffer, waiting when the buffer reaches its maximum capacity. The consumer removes tasks from the buffer and processes them, waiting when the buffer is empty. After each insertion or removal, the appropriate thread is signaled to resume execution.

Synchronization is enforced through a mutex to ensure mutual exclusion while accessing the shared buffer. Condition variables are used to manage waiting and signaling between the producer and consumer threads, ensuring correct execution order and preventing race conditions.
The project is implemented in C++ and focuses on core Operating Systems concepts such as multithreading, concurrency, critical sections, thread synchronization, mutex locks, condition variables, and bounded buffer management
